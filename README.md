# DutyWorld — сайт Minecraft-сервера

Сайт-магазин сервера **DutyWorld** (`DutyWorld.aternos.me`). Структура повторяет reallyworld.me,
но логотип, название, цвета, донаты и герои свои.

Сайт статический: HTML, CSS и JavaScript без сборки. Его можно бесплатно разместить на Cloudflare Pages, Netlify или GitHub Pages.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: слайдер с героями, IP сервера, покупка кейсов с валютой, магазин, герои |
| `description.html` | Описание привилегий, кейсов и услуг |
| `play.html` | Как зайти на сервер + защита аккаунта |
| `payments.html` | Способы оплаты |
| `support.html` | Поддержка и проверка на читы |
| `staff.html` | Набор в состав |
| `doc.html?d=rules` / `agreement` / `privacy` / `cookie` | Документы проекта (берутся из `docs/*.md`) |

## Что где менять

| Что изменить | Файл |
|---|---|
| IP, версии, ссылки на Discord/Telegram, оператор, **номер карты для оплаты** | `assets/js/config.js` |
| Цены, названия, возможности привилегий, кейсы, услуги | `assets/js/data.js` |
| Тексты правил, соглашения, политик | `docs/rules.md`, `docs/agreement.md`, `docs/privacy.md`, `docs/cookie.md` |
| Цвета и оформление | `assets/css/style.css` (переменные в начале файла) |
| Скины героев | `assets/skins/*.png` (см. `assets/skins/CREDITS.md`) |
| Имена и описания героев | `assets/js/app.js`, объект `HEROES` |
| Логотип | `assets/img/logo.png`, `logo-192.png`, `favicon.png` |

Исходный прайс Мирика лежит в `docs/prices.txt`.

> ⚠ Возможности привилегий в `data.js` пока **примерные**. Перед запуском замените их на то, что реально выдаётся на сервере. Если привилегия действует ограниченное время, укажите срок в поле `duration`.

## Как посмотреть сайт на компьютере

Документы загружаются через `fetch`, поэтому сайт нужно открыть через локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Оплата

Сейчас оплата идёт переводом по номеру карты, а донат выдаётся вручную:

1. Игрок выбирает товар, вводит ник и соглашается с условиями.
2. Сайт показывает сумму, номер карты и код заказа (например, `DW-7K2QX9`).
3. Игрок переводит деньги и отправляет чек с кодом в Telegram или Discord.
4. Администратор проверяет поступление и выдаёт донат командой из `data.js` (поле `command`).

Пока поле `payment.cardNumber` в `config.js` пустое, вместо реквизитов показывается «Оплата временно недоступна».

## Публикация

Репозиторий приватный. Бесплатный GitHub Pages работает только с публичными репозиториями, поэтому проще всего опубликовать сайт через **Cloudflare Pages**:

1. Зарегистрируйтесь на https://dash.cloudflare.com.
2. Откройте **Workers & Pages → Create application → Pages → Connect to Git → GitHub** и подключите репозиторий `mirik` (приватные репозитории поддерживаются).
3. Production branch: `main`. **Framework preset** — `None`, **Build command** оставьте пустым, **Build output directory** — `/` (корень репозитория).
4. Нажмите **Save and Deploy**. Сайт появится по адресу вида `https://<имя>.pages.dev`.
5. Впишите этот адрес в `config.js` (`siteUrl`) и в документы, где стоит «[указать адрес сайта]».

После каждого изменения в ветке `main` сайт обновляется автоматически.
