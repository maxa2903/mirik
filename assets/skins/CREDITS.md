# Скины героев

Фанатские скины Minecraft, найденные в открытом каталоге [SkinsMC](https://skinsmc.org).
Персонажи — фанатские версии героев Marvel; права на персонажей принадлежат Marvel / Disney.

| Файл | Герой | Источник |
|---|---|---|
| `spiderman.png` | Человек-паук (главный герой) | https://skinsmc.org/skin/535412 |
| `ironman.png` | Железный человек | https://skinsmc.org/skin/204604 |
| `hulk.png` | Халк | https://skinsmc.org/skin/285169 |
| `thor.png` | Тор | https://skinsmc.org/skin/292361 |
| `black-panther.png` | Чёрная пантера | https://skinsmc.org/skin/209439 |
| `venom.png` | Веном | https://skinsmc.org/skin/239802 |

Чтобы заменить скин: положите PNG 64×64 с тем же именем файла в эту папку.
Имена и описания героев задаются в `assets/js/app.js` (объект `HEROES`).
